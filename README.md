One letter: **A** for coffee. The program writes exactly one character — `A`, no trailing newline, no explanation, no punctuation — to `/output/entry.txt`, for make.fun's "One Letter: Coffee or Tea" bounty. A duel-tested pick: on the Groq proxy judge (gpt-oss-120b) with the judge brief verbatim from the kit, coffee won 6/6 calls over tea in both slot orders.

## Run it

```sh
node main.ts
```
